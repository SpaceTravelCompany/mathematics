## 직관적 설명

**좌표기하학(analytic geometry, coordinate geometry)** 은 데카르트(Descartes)가 창안한, 도형을 방정식으로 번역하는 방법이다. 점은 좌표 $(x, y)$가 되고, 도형은 그 좌표들이 만족하는 방정식이 된다. 이 "기하의 대수화"는 유클리드 기하학의 직관적인 증명을 계산으로 대체하여 훨씬 복잡한 도형을 다룰 수 있게 해주었다. **이차곡선(conic sections)** 은 원뿔을 평면으로 잘랐을 때 나타나는 곡선으로, 원(circle), 타원(ellipse), 포물선(parabola), 쌍곡선(hyperbola)이 있다. 이 곡선들은 행성의 궤도(타원), 포물체의 운동(포물선), 전파의 반사(쌍곡선) 등 자연 현상을 설명하는 기본 모델이다.

## 정의

**직선의 방정식:**
- 기울기-절편형: $y = mx + b$ ($m$: 기울기(slope), $b$: $y$-절편)
- 일반형: $ax + by + c = 0$
- 두 점 $(x_1, y_1)$, $(x_2, y_2)$를 지나는 직선: $\frac{y - y_1}{x - x_1} = \frac{y_2 - y_1}{x_2 - x_1}$ (단, $x_1 \neq x_2$)

**두 직선 관계:** 기울기가 각각 $m_1$, $m_2$인 두 직선이
- 평행: $m_1 = m_2$
- 수직: $m_1 m_2 = -1$
- 이루는 각 $\theta$: $\tan\theta = \left|\frac{m_2 - m_1}{1 + m_1 m_2}\right|$

**원(circle):** 중심이 $(a, b)$이고 반지름이 $r$인 원의 방정식

$$(x - a)^2 + (y - b)^2 = r^2$$

**포물선(parabola):** 초점(focus) $F(p, 0)$과 준선(directrix) $x = -p$에서 거리가 같은 점의 자취

$$y^2 = 4px \quad\text{(초점이 $x$축 위에 있을 때)}$$

**타원(ellipse):** 두 초점 $F_1(-c, 0)$, $F_2(c, 0)$까지 거리의 합이 $2a$로 일정한 점의 자취 ($a > c > 0$)

$$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 \quad\text{(단, $b^2 = a^2 - c^2$)}$$

**쌍곡선(hyperbola):** 두 초점까지 거리의 차의 절댓값이 $2a$로 일정한 점의 자취

$$\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1 \quad\text{(단, $b^2 = c^2 - a^2$)}$$

**이심률(eccentricity):** $e = c/a$ (타원 $0 < e < 1$, 포물선 $e = 1$, 쌍곡선 $e > 1$, 원 $e = 0$).

## 주요 정리와 증명

### 정리 1: 원의 방정식 유도

중심이 $C(a, b)$, 반지름이 $r$인 원 위의 점 $P(x, y)$는 $|PC| = r$을 만족한다. 거리 공식에 의해

$$\sqrt{(x - a)^2 + (y - b)^2} = r$$

양변을 제곱하면 $(x - a)^2 + (y - b)^2 = r^2$을 얻는다.

역으로, 이 방정식을 만족하는 모든 점 $(x, y)$는 중심 $C$로부터의 거리가 정확히 $r$이므로 원 위에 있다.

### 정리 2: 타원의 표준형 유도

두 초점 $F_1(-c, 0)$, $F_2(c, 0)$과 거리의 합이 $2a$ ($a > c > 0$)인 타원을 생각하자. 타원 위의 점 $P(x, y)$는

$$|PF_1| + |PF_2| = 2a$$

거리 공식을 대입하면

$$\sqrt{(x + c)^2 + y^2} + \sqrt{(x - c)^2 + y^2} = 2a$$

첫 번째 제곱근을 우변으로 이항한다.

$$\sqrt{(x + c)^2 + y^2} = 2a - \sqrt{(x - c)^2 + y^2}$$

양변을 제곱한다.

$$(x + c)^2 + y^2 = 4a^2 - 4a\sqrt{(x - c)^2 + y^2} + (x - c)^2 + y^2$$

전개하여 정리하면

$$x^2 + 2cx + c^2 + y^2 = 4a^2 - 4a\sqrt{(x - c)^2 + y^2} + x^2 - 2cx + c^2 + y^2$$

$$4cx = 4a^2 - 4a\sqrt{(x - c)^2 + y^2}$$

양변을 4로 나누고 제곱근 항만 남긴다.

$$a\sqrt{(x - c)^2 + y^2} = a^2 - cx$$

다시 제곱한다.

$$a^2[(x - c)^2 + y^2] = a^4 - 2a^2 cx + c^2 x^2$$

$$a^2(x^2 - 2cx + c^2 + y^2) = a^4 - 2a^2 cx + c^2 x^2$$

$$a^2 x^2 - 2a^2 cx + a^2 c^2 + a^2 y^2 = a^4 - 2a^2 cx + c^2 x^2$$

$-2a^2 cx$가 소거되고, $x$ 항을 모은다.

$$a^2 x^2 - c^2 x^2 + a^2 y^2 = a^4 - a^2 c^2$$

$$(a^2 - c^2)x^2 + a^2 y^2 = a^2(a^2 - c^2)$$

$b^2 = a^2 - c^2$로 정의하면

$$b^2 x^2 + a^2 y^2 = a^2 b^2$$

양변을 $a^2 b^2$으로 나눈다.

$$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$$

### 정리 3: 이차곡선 판별식 (Discriminant of Conic Sections)

일반적인 이차곡선의 방정식

$$Ax^2 + Bxy + Cy^2 + Dx + Ey + F = 0$$

에 대해 판별식 $\Delta = B^2 - 4AC$로 곡선의 형태를 분류할 수 있다.

- $\Delta < 0$: 타원 (또는 원, $A = C$이고 $B = 0$인 경우). $D = E = 0$이면 점으로 퇴화.
- $\Delta = 0$: 포물선
- $\Delta > 0$: 쌍곡선

**증명 개요:** 회전 변환(rotation)을 통해 $B = 0$이 되도록 좌표축을 돌리면, 방정식이 $A'x'^2 + C'y'^2 + \cdots = 0$ 형태가 된다. $A'$와 $C'$의 부호가 같으면 타원, 다르면 쌍곡선, 하나가 0이면 포물선이 된다. $B^2 - 4AC$는 회전에 대해 불변(invariant)이며, 그 부호가 $A'C'$의 부호와 일치한다.

## 예제

**예제 1:** 직선 $y = 2x + 1$과 원 $(x-2)^2 + (y-1)^2 = 5$의 교점을 구하라.

**풀이:** $y = 2x + 1$을 원의 방정식에 대입한다.

$$(x-2)^2 + (2x+1-1)^2 = 5$$
$$(x-2)^2 + (2x)^2 = 5$$
$$x^2 - 4x + 4 + 4x^2 = 5$$
$$5x^2 - 4x + 4 = 5$$
$$5x^2 - 4x - 1 = 0$$

근의 공식으로 $x = \frac{4 \pm \sqrt{16 + 20}}{10} = \frac{4 \pm \sqrt{36}}{10} = \frac{4 \pm 6}{10}$.

$x = 1$ 또는 $x = -1/5$. 대응하는 $y$:
- $x = 1$: $y = 3$
- $x = -1/5$: $y = 2(-1/5) + 1 = 3/5$

따라서 교점은 $(1, 3)$과 $(-1/5, 3/5)$이다.

**예제 2:** 타원 $\frac{x^2}{25} + \frac{y^2}{9} = 1$의 초점과 이심률을 구하라.

**풀이:** $a^2 = 25$이므로 $a = 5$, $b^2 = 9$이므로 $b = 3$. $c^2 = a^2 - b^2 = 25 - 9 = 16$이므로 $c = 4$.

초점: $F_1(-4, 0)$, $F_2(4, 0)$.
이심률: $e = c/a = 4/5 = 0.8$.

**예제 3:** 포물선 $y^2 = 12x$의 초점과 준선의 방정식을 구하라.

**풀이:** $y^2 = 4px$와 비교하면 $4p = 12$, 즉 $p = 3$이다.
- 초점: $F(3, 0)$
- 준선: $x = -3$

확인: 포물선 위의 점 $(3, 6)$에 대해 $|PF| = \sqrt{(3-3)^2 + 6^2} = 6$이고, 준선까지 거리는 $3 - (-3) = 6$으로 일치한다.

## 연결

- **[등고선과 그래디언트](gradient-geometry.html)** : 등고선(contour line)은 $f(x, y) = c$ 형태로, 좌표기하에서 직선과 곡선의 개념을 다변수로 확장한다.
- **[스펙트럼 정리](spectral-theorem.html)** : 대칭행렬의 이차형식(quadratic form)은 이차곡선의 고차원 일반화이며, 주축 정리(principal axis theorem)로 분류된다.
- **[벡터공간 추상화](vector-space-abstraction.html)** : 좌표 $(x, y)$는 $\mathbb{R}^2$ 벡터공간의 원소이며, 모든 기하학적 대상은 벡터의 관점에서 재해석될 수 있다.
